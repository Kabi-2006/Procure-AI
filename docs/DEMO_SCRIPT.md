# Three-minute Demo Script

## Opening — 20 seconds

“Procurement teams receive quotations in different formats and manually compare price, delivery, warranty and payment terms. ProcureAI transforms those documents into one explainable purchasing decision.”

## Workflow — 100 seconds

1. Show the overview and sourcing requirement.
2. Click **Run demo analysis**.
3. Explain that three differently priced supplier quotations were extracted.
4. Show the comparison table.
5. Point out that the cheapest vendor is not necessarily the winner.
6. Explain the visible scoring weights.
7. Click **Approve winner**.
8. Click **Generate PO** and open the PDF.

## Closing — 40 seconds

“The MVP reduces quotation comparison from hours to minutes while retaining human control. The next stage adds supplier portals, invoice matching and integrations with existing ERP and finance systems.”

## Backup

If document processing fails, restart the backend and use the included sample PDFs. If internet access is unavailable, the complete demo still works locally because it requires no external AI API.
